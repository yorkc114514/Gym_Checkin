隱私權政策

本政策說明運動科學實驗室簽到系統如何處理使用者與 Google 資料。

最後更新：2026 年 9 月 26 日

1. 適用範圍

本政策適用於「運動科學實驗室簽到系統」（以下簡稱本系統）。 本系統為軟體工程課程專題，用於實驗室人員簽到、簽退、預約查詢及問題回報。

2. 我們處理的資料

Google 登入資料

使用 Google 登入時，本系統會處理 Google 帳號識別碼、姓名、 Email 與頭像，用來確認身分、建立個人資料並顯示操作人員。 首次登入時，系統另會要求使用者確認方便辨識的姓名， 並將該姓名與 Google 帳號識別碼綁定於個人資料。

簽到與回報資料

  • 簽到、簽退時間、使用身分、責任交接及設備檢查紀錄。
  • 協助簽退的操作人員與被協助人員。
  • 問題回報內容、處理狀態與通知結果。

Gmail 與 Google Calendar

  • Gmail 授權僅用於從指定的管理帳號寄出問題回報通知； 本系統不讀取、顯示或儲存信箱內容。
  • Google Calendar 授權用於讀取指定日曆的預約標題、開始時間與結束時間， 並顯示在預約查詢頁面。本系統不會新增、修改或刪除日曆活動。

3. 資料使用目的

  • 提供使用者驗證與維持登入狀態。
  • 執行簽到、簽退、在場查詢與紀錄查詢。
  • 顯示實驗室預約，並在收到問題時通知管理人員。
  • 維護系統安全、處理異常與改善服務。

4. 儲存、分享與保留

本系統使用 GitHub Pages 提供前端頁面，並使用 Supabase 提供驗證、 資料庫與後端功能。資料不會被販售，也不會用於廣告或不相關的行銷。 僅會在提供本系統功能所必要的範圍內，由 Google、Supabase 與 GitHub 等服務處理。

資料原則上保留至課程專題或實驗室管理需求結束；若不再需要， 管理人員可依請求刪除相關資料，但法律、資安或備份所必要的保留除外。

本機訓練資料

訓練進步圖表只讀取本機訓練紀錄。體重紀錄存在瀏覽器 IndexedDB，每天一筆，不上傳 Supabase；與訓練紀錄一樣，同瀏覽器切換帳號仍共用來源資料。月度成果卡依登入帳號分開存於本機，由上月本機訓練、體重與到訪章建立固定快照，可下載 PNG 或 JSON 備份。產生後修改原始紀錄不會改變已存卡片。體重與月度卡的 JSON 備份分別於各頁面下載、匯入；清除網站資料會刪除本機紀錄，且不會隨 Google 帳號自動同步。

訓練助手的動作、重量、次數、組數、日期與備註僅儲存於目前瀏覽器的 IndexedDB；休息計時設定儲存於 localStorage。這些資料不會上傳 Supabase，不會隨 Google 帳號同步。同一裝置與瀏覽器切換帳號仍可見相同紀錄。使用者可逐筆刪除紀錄或清除本網站資料，也可自行匯出及匯入 JSON 備份。清除網站資料、無痕模式結束或瀏覽器回收儲存空間可能造成紀錄遺失。

「我的健身足跡」另在本機 IndexedDB 保存帳號識別碼、簽到紀錄識別碼及成功簽到／本人簽退時間，用於每天去重與個人回顧，不將集章或成果卡上傳後端。紀錄依帳號區隔；備份須以同一帳號匯入。此功能不保存 Google 登入憑證，正式出入紀錄仍依原簽到系統處理。

5. Google API 資料使用

本系統對從 Google API 取得資訊的使用與傳送，將遵守 Google API Services User Data Policy ，包含 Limited Use 要求。

6. 使用者選擇

使用者可登出本系統，或前往 Google 帳號的第三方連結管理頁面 撤銷授權。若需查詢、更正或刪除資料，請透過下方聯絡方式提出。

7. 聯絡方式

隱私權或資料處理相關問題，可透過 GitHub Issues 聯絡專案維護者。請勿在公開回報中張貼密碼、token 或其他敏感資料。
